## How to refresh

Take new screenshots from a test Moodle (the `oksigenia/moodle` Docker image, English interface, fictional site and users) after a plugin upgrade if the panel UI changes (e.g. new control, redesigned trigger, settings reorganised). Match the naming convention above so the carousel order on the Marketplace stays the same.

Target dimensions: 1100-1900 px wide, PNG, under 500 KB each. Crop or scale down before committing if larger.
